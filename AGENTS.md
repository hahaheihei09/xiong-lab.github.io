# Website content updates

- Each paper acceptance news post must be accompanied by an entry in both `content/publication/_index.md` and `content/publication/_index.zh.md` in the same change.
- Match author order and journal name to the accepted manuscript. Mark a paper as accepted until its final publication details are available; do not invent a DOI, volume, or page number.
- Keep the publication totals and last-updated dates in both languages in sync with the list.
- Keep entries in each publication category in reverse chronological order, with the newest work first, in both languages.
- When a news post has a `featured.jpg`, the theme displays it automatically. Do not embed the same image again in the post body.
